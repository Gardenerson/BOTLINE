# บ้านบัญชี — แพ็กเกจ Deploy

นี่คือเว็บแบบ static (ไม่มี backend และไม่มี dependency) จึงนำไฟล์ `index.html` ไปวางบน static hosting ได้โดยตรง

## ใช้งาน

1. อัปโหลดโฟลเดอร์นี้ หรืออย่างน้อยไฟล์ `index.html` ไปยังบริการที่ใช้ deploy
2. กำหนด root ของเว็บไซต์ให้ชี้มายังโฟลเดอร์นี้
3. เปิดเว็บไซต์ผ่าน URL ที่บริการนั้นสร้างให้

## หมายเหตุ

- ฟอร์มเพิ่มรายการทำงานในหน้าเว็บทันที แต่ข้อมูลอยู่ในหน่วยความจำของเบราว์เซอร์ จึงหายหลังรีเฟรชหน้า
- หากต้องการบันทึกข้อมูลถาวร ให้เชื่อมต่อ backend/database เช่น Supabase, Firebase, หรือ API ของระบบคุณ
